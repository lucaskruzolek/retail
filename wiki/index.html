Retail

Sistema de gestión y punto de venta para una librería: ventas de mostrador, caja, clientes con cuenta corriente, catálogo con listas de precios de proveedores, compras y copias de seguridad. Aplicación de escritorio en .NET 8, WPF y SQL Server, hecha como proyecto de cátedra.

Arquitectura

Un monolito de escritorio con arquitectura limpia: las dependencias apuntan hacia el dominio, y el compilador lo impone con las referencias entre proyectos. La interfaz y la consola son dos puntos de entrada a los mismos casos de uso.

ComponenteTecnología
Lenguaje y runtimeC# 12, .NET 8 LTS
InterfazWPF con CommunityToolkit.Mvvm 8.3.2 y WPF-UI 4.0.0
PersistenciaEntity Framework Core 8.0.11 y SQL Server Express
ValidaciónFluentValidation 11.11.0
Planillas de proveedoresMiniExcel 1.34.2
Contraseñas y registrosBCrypt.Net-Next 4.0.3 y Serilog 4.2.0
PruebasxUnit, FluentAssertions y NSubstitute
